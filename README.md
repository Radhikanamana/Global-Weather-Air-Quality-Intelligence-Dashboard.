# 🌍 Global Weather & Air Quality Intelligence Dashboard

An interactive **Power BI dashboard** designed to analyze global weather conditions and air quality indicators across different cities and countries. The dashboard provides interactive visualizations, KPIs, maps, trends, and filters to help users explore environmental conditions and identify patterns.

 ✨ Features

| Feature | Description |
|---|---|
| 🌍 **Global Overview** | Provides an overall view of weather and air quality conditions across different locations. |
| 🌡️ **Weather Analysis** | Analyzes temperature, humidity, wind speed, pressure, and other weather indicators. |
| 💨 **Air Quality Analysis** | Tracks air-quality indicators and pollutant levels across locations. |
| 🗺️ **Interactive Map** | Displays geographical weather and air-quality information by location. |
| 📊 **KPI Cards** | Shows important metrics such as temperature, humidity, wind speed, and air-quality values. |
| 📈 **Trend Analysis** | Visualizes changes in weather and air-quality metrics over time. |
| 🏙️ **City Comparison** | Enables comparison of environmental conditions between different cities. |
| 🔍 **Interactive Filters** | Allows users to filter the dashboard by country, city, date, and other available attributes. |
| 📅 **Time-Based Analysis** | Examines weather and air-quality patterns across different dates and periods. |
| 📊 **Dynamic Visuals** | Visualizations update automatically based on selected filters and slicers. |
| 🎨 **Interactive Dashboard** | Provides an easy-to-use interface for exploring environmental data. |
| 💡 **Data-Driven Insights** | Helps identify patterns, variations, and relationships in weather and air-quality data. |
